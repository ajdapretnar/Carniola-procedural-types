# Carniola-procedural-types
Scripts and dataset for the *Beyond “noise”: the function of procedural speech in the Carniolan Provincial Diet, 1861-1918* DH 2027 paper.

### Structure

- `codebook.xlsx`: codebook with codes and descriptions for procedural type annotation.
- `prompt.txt`: prompt for LLM annotation

- `data`:
  - `Kranjska2.0_procedural_annotated.csv`: manually and LLM-annotated procedural speech types
  - `Kranjska2.0_regular_MPs.csv`: speeches in the Carniolan Provincial Diet by regular MPs

- `scripts`:
  - `speech-types-by-category`: script for displaying heat map visualizations of procedural speech shares by category
  - `speech-types-statistics`: script for displaying core statistics and procedural speech share over time
